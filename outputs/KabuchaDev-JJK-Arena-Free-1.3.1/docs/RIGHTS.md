The EULA permits sharing original mods but restricts selling/trying to make money from them and sharing modified game distributions. The Usage Guidelines' server-donation conditions should not be treated as blanket permission to fund mod development. A free download plus a donation button is not certified compliant by this package.
- [Zeefski Jujutsu Kaisen Craft 3.2.1](https://www.curseforge.com/minecraft/modpacks/zjjk/files/8509973): obtain both matching client and server packs from the author's file page. The originally tested server file is `ZJJK_3.2.1server-pack.zip`, file ID 8510031; if removed, do not replace with an unverified mirror or assume a later version is compatible.
