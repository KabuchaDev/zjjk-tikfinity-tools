# Mở server và sân đấu

1. Bấm đúp **BAT-SERVER-VA-DAU-TRUONG.cmd** trong thư mục này.
2. Đợi dòng **Da bat server va mo tran** hoặc **Server va san dau da chay**. Thường mất khoảng 30–90 giây khi mở mới.
3. Mở Minecraft đúng modpack đang dùng, vào **127.0.0.1:25566**.
4. Gõ **/jjkarena watch** để vào khu quan sát.

Nếu server đã chạy, nút không chạy thêm server và không dọn trận đang diễn ra. Nếu trận đang tạm dừng, mở **TIEP-TUC-TRAN.cmd** khi muốn chơi tiếp.

Để thử quân: mở **BANG-THU-NHAN-VAT.cmd**.

Để nhận tương tác LIVE: mở **TikFinity Desktop**, kết nối đúng phiên LIVE; mở **Streamer.bot**; rồi mở **BAT-KET-NOI-TIKTOK.cmd**. Nếu bộ nối đã chạy, không cần mở thêm. Kiểm tra bằng **XEM-BO-DEM-VA-KET-NOI.cmd**: cả hai kết nối và trận đều phải sẵn sàng.

Để kết thúc: mở **TAT-KET-NOI-TIKTOK.cmd**, rồi **TAT-SERVER.cmd** để lưu và tắt server. Không tắt máy khi server chưa lưu xong.

Nút khởi động server không tự mở LIVE trên TikTok.
